# Writing Skill

This skill helps you write and edit various types of content.

## Usage

Use this skill when the user wants to:
- Write reports and documentation
- Draft emails and communications
- Create technical documentation
- Edit and improve existing content

## Workflow

1. **Understand the purpose** and audience
2. **Gather information** from context/files
3. **Draft the content** with clear structure
4. **Review and refine** for clarity and tone

## Content Types

### Reports
- Executive summary
- Background/Context
- Analysis
- Recommendations
- Conclusion

### Documentation
- Overview
- Getting Started
- Usage Examples
- API Reference
- Troubleshooting

### Emails/Communications
- Clear subject line
- Context/Background
- Action items
- Next steps

## Tips

- Know your audience (technical vs non-technical)
- Use clear, concise language
- Structure with headings and bullets
- Include examples when helpful
- Proofread for grammar and clarity
